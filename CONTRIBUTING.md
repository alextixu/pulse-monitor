# Contributing

Thank you for contributing to Pulse.

## Before You Start
- Open an issue for bugs or feature ideas using the templates.
- Keep pull requests focused and small.

## Development
- Restore dependencies: `dotnet restore Pulse.sln`
- Build locally: `dotnet build Pulse.sln`

## Pull Requests
- Describe what changed and why.
- Link related issues (for example: `Closes #123`).
- Ensure CI passes before requesting review.
