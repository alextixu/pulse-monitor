# ui

## summary
Pulse.App is a single-process Avalonia 11.3.22 tray app: Program.cs parses flags (--minimized/--demo/--screenshot <dir>/--quit/--elevated-relaunch), acquires a named-mutex single-instance guard, then App.OnFrameworkInitializationCompleted builds one Microsoft.Extensions.DependencyInjection container (App.axaml.cs:235-295) holding the platform providers, MonitoringService (battery + hardware poll loops), FanModeService, TelemetryLogger, TrayService and all six view models as singletons. MonitoringService polls on two PeriodicTimers (hardware every 1 s while TelemetryEnabled, which is the default; batteries every 30 s) and marshals every result onto Dispatcher.UIThread, where it sets CommunityToolkit [ObservableProperty]s and raises HardwareUpdated/BatteriesUpdated/SummaryChanged. All five tab view models subscribe to those events in their constructors and rebuild their observable item collections on every tick regardless of whether the popover is shown or which tab is active; nothing is gated on TabViewModelBase.IsActive or MainViewModel.IsPopoverVisible (the latter is written at PopoverWindow.axaml.cs:119/129 but never read). The UI is one frameless, Topmost, transparent PopoverWindow (448x708 window around a 400x660 card) that is created once, shown next to the tray at the bottom-right of the primary screen's work area, and only ever hidden (Escape, deactivation, close-cancel), so its whole visual tree and bindings stay live forever. Tab content is a ContentControl with DataTemplates mapping view models to views (App.axaml:29-45), compiled bindings on, Fluent theme with a custom token dictionary (Styles/Theme.axaml) and style classes (Styles/Controls.axaml), Inter font via Avalonia.Fonts.Inter, 46 StreamGeometry icons, two custom controls (RingGauge, StatPill), and ColorView from Avalonia.Controls.ColorPicker for custom RGB colours. Low-battery toasts are in-window WindowNotificationManager cards (never OS notifications). The tray icon is an Avalonia TrayIcon whose WindowIcon is rendered with SkiaSharp and cached by content (uncommitted fix for a GDI-handle leak). Strings.cs is a static class of Traditional-Chinese constants bound via x:Static (no resx, no culture switching). Demo/* provides fake IBatteryProvider/IHardwareMonitor/IRgbController/elevation/auto-start/settings-store implementations that --demo swaps into DI; --screenshot additionally drives ScreenshotService, which renders every tab in light and dark (plus three fan-mode variants) with RenderTargetBitmap and exits. Everything the UI consumes is reachable through MonitoringService, FanModeService, SettingsService, IHardwareMonitor.SetFanAsync, IRgbController, IElevationService and IAutoStartService; that set is the natural IPC contract for the planned headless agent / on-demand UI split.
